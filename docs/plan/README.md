# Plans

Implementation plans and design roadmaps for VOID.

## Structure

- `done/` -- completed plans; all phases merged and verified
- `draft/` -- active or upcoming plans; phases may be in progress or awaiting implementation

## Convention

Each plan lives in its own subdirectory named after the initiative. Multi-phase plans contain one file per phase plus an index or roadmap document. Superseded versions of a plan move to an `archive/` subdirectory within the initiative folder.
