## Deprecated Bridge Removal Decision

`VOIDBuilder.profile(DriverFactory.Profile)` and `VOID.start(DriverFactory.Profile)` were
introduced as deprecated bridges in I6.4 (SessionProfile preamble). After the `DriverFactory`
rename to `SeleniumDriverFactory` and relocation to `domain.automation.web.selenium.driver`,
`DriverFactory.Profile` ceases to exist at any FQN reachable from the kernel without a
kernel->domain WI dependency violation. There is no way to keep these bridges without
importing `domain.automation.web.selenium.driver.SeleniumDriverFactory` into `core.runtime`
(architecture violation: kernel importing web-domain WI).

**Decision**: Both deprecated bridge methods are removed in this phase. The migration guide
documents the replacement:
- Bridge methods removed: `VOIDBuilder.profile(DriverFactory.Profile)`, `VOID.start(DriverFactory.Profile)`
- Replacement: `VOIDBuilder.profile(SessionProfile)` -- use `SessionProfile.DEFAULT`, `SessionProfile.CI`, etc.
- For `DriverFactory.Profile`: type is renamed to `SeleniumDriverFactory.Profile` in `domain.automation.web.selenium.driver`

This is a breaking change aligned to the 1.0.0 boundary (per plan).

## Kernel Purity Exception Updates

`core.actions.Action` has `resolve(Executor)` returning `LocatorDescriptor` (currently
`elements.locator.LocatorDescriptor`). After 6.4, `LocatorDescriptor` is in
`domain.automation.web.locator.LocatorDescriptor`. The kernel (`core.actions.*`,
`core.actions.hooks.ActionHandler`, `core.actions.HookChainAction`) will import from
`domain.automation.web.locator` -- a domain-owned package.

This is a documented pre-existing temporary exception (closes I9.4 when `resolve()` is
removed from the kernel contract or replaced with a neutral type). The exception survives
6.4 but the FQN reference in `KernelBoundaryRulesTest` changes from `elements.locator.*`
to `domain.automation.web.locator.*`.

Similarly, the deprecated `Action.resolve(UIEngine)` bridge references `UIEngine` which
moves to `domain.automation.web.engine.UIEngine`. This exception also closes I9.4.
